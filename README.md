# FinanFocus – Frontend (Obligatorio 2)

React 19 + Vite, React Router, Redux Toolkit, React Hook Form, Recharts.

```
npm install
npm run dev      # http://localhost:5173
npm run build
```

Variable: `VITE_API_URL` (ver `.env.example`). En Vercel: Settings > Environment Variables.
El backend debe tener la URL del frontend en `CORS_ORIGIN`.
